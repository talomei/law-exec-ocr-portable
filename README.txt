📖 完整使用文档：请打开 _docs/USER_GUIDE.md

【Windows】  双击 start.bat
【macOS】    双击 start.command
             首次使用：先双击 _platform/macos-arm64/_INSTALL_FIRST_TIME.command
【Linux】    终端运行 ./start.sh

🌐 启动后浏览器自动打开 http://127.0.0.1:8501
⏹  关闭启动窗口即可停止服务

📁 目录结构：
  start.bat / start.command / start.sh   ← 启动器
  _platform/                              ← 各平台二进制
  _app/                                   ← 应用源码（可读可改）
  _docs/                                  ← 文档
  _test_samples/                          ← 测试样本
  _logs/                                  ← 运行日志
